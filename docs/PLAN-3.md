## 1. 问题
1. 双线图里「导入」线不是蓝色：它沿用了主题色 --accent（#c96442，橙褐），阵亡线是红色，两条颜色太接近；标题却写了「蓝：导入，红：阵亡」，文案与实际不符。
2. 页面叫「乱葬岗」，但内容已经是账号存活的整体统计，名字不符、结构混在一起。

## 2. 方案
### 2.1 颜色（先修，改动很小）
- 新增 .chart-line-imported / .chart-dot-imported，固定蓝色（深浅色下都可读），阵亡线保持红色。
- 图下方加图例（蓝点 导入 / 红点 阵亡），标题里去掉「蓝红」文字说明。
- 点的形状也区分（导入圆点、阵亡方点），不只靠颜色。

### 2.2 页面重排
- 左侧导航：「乱葬岗」改名「账号存活」。内部页面 id、接口路径（/api/graveyard/*）不改，避免动后端。
- 页面内分三个标签：
  1. 概览：累计导入、当前存活率、活过 7/30 天；平均存活曲线；每日导入 vs 阵亡（7/30 天切换，切换器放在图旁，只影响这张图）。
  2. 乱葬岗：原来的墓碑列表 + 分页 + 阵亡数/平均寿命/近 7 天阵亡 + 每日阵亡曲线。
  3. （可选，先不做）导入记录。
- 默认打开「概览」。记住上次所在标签（沿用 prefs.js 的记忆方式）。
- 说明文案统一：只读本地数据，不向 Claude 发请求；只统计现存账号和乱葬岗上线后阵亡的账号。
- 「刷新（本地）」按钮保留，放页面右上，对三个标签通用。

### 2.3 不做
- 不改数据库、不改接口返回结构、不改定时检查等其他功能。
